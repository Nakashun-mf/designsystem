# ユーザー向けガイド

## これが何か

**丸い雲・やわらかいピンク空**を主役にしたデザインシステムです。  
イベント特設サイトの色をそのまま真似るより、「ふくらんだかたち」で寄せます。

## Web で使う

1. `css/tokens.css` と `css/components.css` を読み込む
2. 基本は `<html data-theme="soft-cloud">`
3. `demos/index.html` を見本にする（背景に雲が浮かびます）

## PowerPoint で使う

1. まず `soft-cloud-full.pptx` か `pack-soft-cloud-only.pptx`
2. 文字を差し替える
3. 公式KVを使うときは権利確認

### フォント代替

| Web | PowerPoint で近いもの |
|---|---|
| Zen Maru Gothic | 游ゴシック / 丸ゴシック |
| M PLUS Rounded 1c | 丸ゴシック / Yu Gothic |

## 注意

公式ロゴ・イラストの無断複製はしないでください。このパッケージは色とレイアウトの再現用です。
