# せいぎデザイン — 要件・設計仕様

日付: 2026-09-16  
リポジトリ: `Nakashun-mf/designsystem`（メインリポジトリにすべて配置）  
ステータス: 要件確定（実装前レビュー待ち）

## 1. 目的

生産技術室の誰もが、デザインを意識せずに**見た目の揃った資料**を作れるようにする。  
しぐれうい系デザインシステム（soft-cloud）の「やわらかく親しみやすい」空気感を残しつつ、大成工業／ノーリツグループの色（大成ブルー・ノーリツレッド）と部署文脈に寄せた社内用フォーク「**せいぎデザイン**」を同一リポジトリ内に追加する。

## 2. 利用者と成功条件

- **利用者**: 生産技術室（技術系）。パワポ・エクセルを日常的に使うメンバー
- **成功条件**
  - テンプレを開いて文言を差し替えるだけで、色・余白・ヘッダーが揃う
  - ジグの設計レビュー（DR）資料がテンプレだけで一通り組める
  - 色やアイコンの微修正は `seigi-design/` 内のトークン／マークだけで足りる
  - 最新成果物は Box から取得できる

## 3. スコープ

### 含む（第1弾）

- 同一リポジトリ内フォーク `seigi-design/`（既存 soft-cloud は参照用に維持・ほぼ変更しない）
- せいぎ用トークン（大成ブルー＋ノーリツレッド＋やわらか背景）
- 簡易マーク（雲＋歯車 SVG）＋社名／部署名テキスト
- PowerPoint: 基本・改善・工程設備・朝会短共有・**ジグDR**・汎用スライド／部品を厚めに
- Excel: 議事録連絡票・チェックリスト点検・工程表・数値集計表紙付き・**ジグDR指摘宿題帳票**・部門テキスト差し込み例
- 一括生成スクリプトと `dist/` ZIP
- Box へのアップロード
- ユーザー向け／開発者向け README

### 含まない（非目標）

- 公式ロゴ・公式KV・公式イラストの複製・同梱
- 既存 soft-cloud パッケージの破壊的リネームや削除
- Word／社内ポータル本体／承認ワークフローシステム
- さくらのレンタルサーバー公開（必要なら別途）

## 4. 構成

```
seigi-design/
  VERSION
  README.md
  README_USERS.md
  README_DEVELOPERS.md
  tokens/                 # 正のトークン
  assets/mark/            # 雲＋歯車マーク（SVG）
  css/                    # デモ確認用（任意）
  demos/
  ppt/                    # 生成 PPTX
  excel/                  # 生成 XLSX
  scripts/                # PPT / Excel 一括生成
  dist/                   # Box 配布用 ZIP のビルド出力
```

既存の `tokens/` `css/` `ppt/` 等（しぐれうい系）は触らない。せいぎ側はここだけをメンテ対象とする。

## 5. ブランド・配色

| 役割 | HEX | 根拠 |
|---|---|---|
| 大成ブルー（主） | `#00315E` | 大成工業サイト見出し・リンク主色 |

- テキスト併用: 「大成工業」「生産技術室」「せいぎデザイン」

## 6. テンプレート一覧（第1弾）

### PowerPoint

- **基本セット**: 表紙・アジェンダ・目次・締め・連絡先
- **改善**: 現状→問題→なぜなぜ→対策→効果→横展
- **工程／設備**: 工程フロー、設備概要、ポイント説明
- **朝会・短共有**: 3〜5枚パック
- **ジグDR（設計審査＋デザインレビュー）**: 目的／要求、構造・機構、安全・干渉、公差・材質、指摘一覧、宿題・期限、合否
- **汎用**: 2列比較、引用、写真＋注釈、スケジュール、表、注意喚起、Q&A
- **部品（layouts）**: 表紙／節区切り／箇条書き／数値KPI／Before-After／リスク／チェック／写真グリッド／注釈吹き出し／せいぎヘッダー・フッター

### Excel

- 議事録・連絡票
- チェックリスト／点検表
- 工程表・簡易スケジュール
- 数値集計（表紙付き）
- ジグDR帳票（指摘・宿題: ID／箇所／重要度／担当／期限／状態）
- 部門テキスト差し込み例（社名＋生産技術室＋せいぎマーク）

## 7. 生成と配布

1. `seigi-design/scripts/` で PPT／Excel を一括生成
2. `seigi-design/dist/` に次を出力  
   - PowerPoint 一式 ZIP  
   - Excel 一式 ZIP  
   - スターター ZIP（よく使う最小セット）
3. **Box にアップロード**（フォルダは実装時に確認または作成）
4. README に「最新は Box」「再生成手順」を記載

トークン変更 → スクリプト再実行 → dist 更新 → Box 更新、の運用を前提とする。

## 8. 制約・注意

- 公式の二次配布ではない。社内テンプレ用途
- 公式ロゴはユーザー提供がない限り入れない（簡易マークで代替）
- Box MCP が使えない場合は CLI／手動アップロード手順を README に残す
- 微修正中心の運用を崩す大きなリデザインは第1弾の対象外
