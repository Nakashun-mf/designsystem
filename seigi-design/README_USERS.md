# せいぎデザイン — ユーザー向け

## これでできること

デザインを考えなくても、開いた瞬間に色・余白・ヘッダーが揃った資料になります。

## PowerPoint

| ファイル | 用途 |
|---|---|
| `seigi-starter.pptx` | 最初の1本 |
| `seigi-basic.pptx` | 表紙〜締め |
| `seigi-kaizen.pptx` | 改善報告 |
| `seigi-process.pptx` | 工程・設備 |
| `seigi-standup.pptx` | 朝会・短共有 |
| `seigi-jig-dr.pptx` | ジグ設計レビュー |
| `seigi-generic.pptx` | 汎用スライド集 |
| `layouts/*.pptx` | 部品単体 |

## Excel

| ファイル | 用途 |
|---|---|
| `seigi-minutes.xlsx` | 議事録・連絡票 |
| `seigi-checklist.xlsx` | チェック／点検 |
| `seigi-schedule.xlsx` | 工程表 |
| `seigi-metrics.xlsx` | 数値集計（表紙付き） |
| `seigi-jig-dr.xlsx` | DR指摘・宿題 |
| `seigi-department-text.xlsx` | 部門テキスト例 |

## 表記

- 会社: 大成工業株式会社
- 部署: 生産技術室
- システム名: せいぎデザイン
- マーク: `assets/mark/seigi-mark.svg`（公式ロゴは使わない）

## 色の使い方

- 見出し・ヘッダー: 大成ブルー
- 注意・強調だけ: ノーリツレッド
- 背景: やわらかい水色〜白（触らなくてOK）
